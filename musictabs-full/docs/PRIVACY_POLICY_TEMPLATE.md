# Политика конфиденциальности [НАЗВАНИЕ ПРИЛОЖЕНИЯ]

Дата последнего обновления: [ДАТА]

[НАЗВАНИЕ ПРИЛОЖЕНИЯ] ("мы", "приложение") уважает конфиденциальность
пользователей. Этот документ описывает, какие данные приложение
собирает и как их использует.

## 1. Доступ к микрофону

Приложение запрашивает разрешение на использование микрофона для
работы функции "Тюнер". Аудио с микрофона обрабатывается **полностью
на устройстве пользователя**, никуда не передаётся и не сохраняется.

## 2. Загружаемые пользователем аудиофайлы

Функция "Разбор трека на аккорды" требует загрузки аудиофайла,
выбранного пользователем. Этот файл передаётся по защищённому
соединению (HTTPS) на наш сервер для анализа и удаляется с сервера
сразу после обработки. Мы не используем эти файлы для каких-либо
целей, кроме предоставления результата анализа, и не передаём их
третьим лицам.

## 3. Данные о покупках

При оформлении подписки обработка платежа полностью выполняется
Google Play. Мы не получаем и не храним данные твоей банковской карты.
Мы получаем только факт наличия активной подписки, чтобы включить
Pro-функции.

## 4. Реклама

Бесплатная версия приложения показывает рекламу через Google AdMob.
AdMob может собирать обезличенные технические идентификаторы для
показа релевантной рекламы в соответствии с [политикой Google
относительно данных](https://policies.google.com/technologies/partner-sites).
Пользователь может ограничить персонализацию рекламы в настройках
своего Android-устройства.

## 5. Хранение данных на устройстве

Приложение хранит на устройстве (не передавая на сервер):
- выбранный инструмент и его строй;
- счётчик использованных бесплатных разборов трека за месяц.

Эти данные удаляются при удалении приложения.

## 6. Права пользователя

Вы можете в любой момент отозвать разрешение на микрофон в настройках
Android, удалить приложение (что удалит все локальные данные), либо
написать нам на [ТВОЙ EMAIL] с вопросом об удалении каких-либо данных,
связанных с вашими загрузками.

## 7. Изменения политики

Мы можем обновлять эту политику. Актуальная версия всегда доступна по
этому адресу.
